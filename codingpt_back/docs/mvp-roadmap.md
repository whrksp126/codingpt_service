# 원격 조작 서비스 MVP 로드맵

> **정본 기획** = 새 기획서(Final/MVP). **계약** = [`runner-contract.md`](./runner-contract.md). **현재 토대** = [`byo-pc-status.md`](./byo-pc-status.md).
> 모든 제품 결정은 확정 완료(2026-07-09). 이 문서는 착수 순서와 각 마일스톤의 완료 기준(DoD)을 정의한다.
> 원칙: 마일스톤은 순서대로. 각 마일스톤이 끝날 때마다 **사용자가 체감 가능한 상태**여야 한다.

## 확정 결정 요약 (근거는 memory/기획서)

- 정체성: **원격 조작 서비스** (AI 서비스 아님). AI = 사용자 자기 CLI·자기 구독(BYO), 우리 LLM 비용 0.
- 기존 클라우드 엔진(우리 키 SDK+토큰과금): **코드까지 즉시 전부 제거.** 웹 바이브코딩 동결(랜딩+결제만).
- 첫 화면 = 만들기/연결 허브. 워크스페이스 기본 = 터미널, 채팅 시작 시 데몬이 구조화 spawn.
- 이어받기(PC 대화 목록→폰 resume) = MVP 킬러 피처. 승인 = 사용자 CLI 설정 존중.
- IDE = 기존 커스텀 유지+소스 레이어만 교체. 자동 저장 + AI 우선(baseMtime). code-server 폐기.
- 동기화 = objectstore git-bundle, 코드만 동기화(환경은 러너별 재구성). 충돌 = 파일 택1 + rescue.
- 클라우드 러너 = BYO 로그인, 크레덴셜 암호화 동면, 실행시간 과금. 라우팅 = 자동 + 전환만 원탭.
- 푸시 = 핵심 3종. 어댑터 = claude-code + generic. 데몬 = Mac(메뉴바+서명·공증) + Linux(systemd).

## M4 — 동기화 (git-bundle 체크포인트 + 핸드오프)

| # | 작업 | 비고 |
|---|---|---|
| 4-1 | checkpoint/materialize: shadow 커밋(사용자 히스토리 불변), objectstore git-bundle 허브, 대용량 제외+재설치 원칙 | 상세 설계 문서 선행(M0-3의 sync 채널 구체화) |
| 4-2 | 자동 체크포인트: 턴 종료/주기(~30s)/전환 직전 | |
| 4-3 | 충돌: 3-way 탐지 → **파일 단위 택1 UI** + "전부 한쪽" + rescue 브랜치 보존. 충돌 중 에이전트 정지 | code-server 없이 자체 완결 |
| 4-4 | 에이전트 **세션 파일 포함**(대화 이어가기) + 워크스페이스별 제외 설정(excludeFromCloud) | 프라이버시 고지 |

**DoD**: PC에서 작업 → 체크포인트 → 다른 러너에서 materialize하면 코드+대화가 그대로. 충돌 시 데이터 유실 0.

## M5 — 클라우드 러너 BYO + 자동 라우팅 + 과금

| # | 작업 | 비고 |
|---|---|---|
| 5-1 | 러너 코어를 격리 컨테이너에서 구동(기존 sandbox 격리 자산 재사용: CapDrop/egress/TTL) | microVM은 이후 고도화 |
| 5-2 | **BYO 로그인 가이드 플로우**: 러너 터미널의 OAuth URL → 앱 인앱브라우저 중계 | 입문자 이탈 방지에 공들일 것 |
| 5-3 | **크레덴셜 암호화 동면** + scale-to-zero + 콜드스타트 UX("환경 깨우는 중") | 약관에 "사용자 소유 공간" 명시 |
| 5-4 | **자동 라우팅**: PC 온라인=로컬, 오프라인=원탭 "[클라우드에서 계속]"(체크포인트 복원). macOS/iOS 종속 워크스페이스는 폴백 비활성 표시. 런타임 버전(.nvmrc/engines) 존중 | 환경 차이 원칙 |
| 5-5 | **실행시간 계측**(처음부터, append-only 원장) + 요금제 재설계(무료: 로컬 무제한+클라우드 소량 / Pro: 실행시간 쿼터) + PortOne/IAP 상품 개편 + 대역폭 soft limit | 과금 근거 소급 불가 |

**DoD**: PC 꺼져도 원탭으로 클라우드에서 이어짐. 클라우드 사용이 계측·과금됨.

## 리스크 메모

- **비문서화 CLI 프로토콜**(stream-json stdin·승인): 버전업 시 파손 가능 → M1-2의 스모크 테스트가 감시선. 파손 시 generic(터미널)으로 자동 강등.
- **M0 철거 후 M1 완성까지 AI 기능 공백**: 의도된 결정(빅뱅). M1을 최우선 속도로.
- 교육 트랙(레슨/TTS 등)은 이 로드맵과 독립적으로 현행 유지.
